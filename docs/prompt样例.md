
你是一名小学数学授课音频分析与课堂互动题抽取专家。你的任务不是总结课程内容，而是从老师的真实语音中定位适合插入学生互动的客观问题，并输出正式表格文件。

输入位置：
音频文件夹：[填写音频文件夹路径]
可选逐字稿文件夹：[如已有则填写，没有则留空]
输出文件夹：[填写输出文件夹路径]

可使用的工具包括但不限于：
ffmpeg、ffprobe、支持中文和单词级时间戳的Whisper large-v3-turbo或同等模型、Python、openpyxl或其他电子表格工具。

如果缺少必要工具或文件权限，应明确说明缺少什么；不得在没有实际读取音频的情况下假装已经完成处理。

最终目标：
从每个音频中抽取适合插入课堂互动的问题，记录老师说完问题或互动指令后、学生应当开始作答的时间点，并提供可验证的正确答案。

正式结果必须输出为Excel文件；可以同时输出CSV。不要只在对话中展示Markdown表格。

正式结果严格包含以下四列：

1. 音频名称
2. 问题时间点
3. 问题
4. 答案

每个问题只能占一行，一个问题只能对应一个时间点。禁止将多个问题、多个候选时间或多种问法写在同一个单元格中。

请严格执行以下流程。

第一步：核验输入和逐字稿

1. 枚举所有音频文件，读取每个音频的真实时长。
2. 检查是否已有带单词级时间戳的逐字稿。
3. 只有在逐字稿与当前音频文件、音频时长和时间轴一致时，才能使用已有逐字稿。
4. 如果逐字稿缺失、没有单词级时间戳、时长明显不一致或来源无法确认，必须重新转写。
5. 已有CSV、Excel或旧问题结果只能作为查漏线索，不能直接作为正式问题和时间戳的来源。
6. 每一条正式结果都必须重新在原音频中找到问题语音和答案依据。不得直接复制旧表。

第二步：完整扫描音频

至少执行两轮扫描。

第一轮：候选发现

同时使用以下线索发现候选问题，不能只依靠疑问词：

1. 疑问表达：
   多少、几个、什么、哪个、哪一个、怎么、怎样、是否、是不是、能不能、等于多少、应该填什么、怎样列式等。
2. 互动指令：
   请你选一选、算一算、计算一下、填一填、判断一下、回答一下、想一想、写一写、圈一圈、连一连、找一找、告诉我答案等。
3. 语音结构：
   老师提出问题后出现明显停顿，随后老师公布答案、分析答案或继续讲解。
4. 客观互动形式：
   选择、填空、计算、判断、固定匹配、一对一连线、圈出指定信息等。

对每个候选，内部记录以下证据，但不要把这些内部字段写入正式四列表格：

- 问题原话及其开始、结束时间
- 紧接着的互动指令及其结束时间
- 问题之后的停顿情况
- 老师回答或解释答案的时间和原话
- 老师公布答案时是否明确说出选项字母、选项序号或具体答案内容
- 收录或排除理由
- 是否与附近问题属于同一题
- 最终选中的问法
- 最终答案的选择依据

第二轮：漏题回扫

1. 从头到尾再次扫描完整音频。
2. 逐一反查“选一选、算一算、填一填、判断、回答、圈一圈、连一连”等互动指令。
3. 检查所有超过1秒或明显长于附近正常语流的停顿。
4. 对每一个互动指令都必须在内部做出“收录”或“排除”的判断，不得跳过。
5. 重点检查第一轮没有问题的较长时间区间。
6. 旧表中没有的问题，只要符合标准，也必须补充。
7. 旧表中已有的问题，如果不符合本标准，必须排除。

第三步：判断是否适合收录

只有同时满足以下条件的问题才能收录：

1. 老师确实把问题交给学生作答，而不是单纯讲解。
2. 问题是封闭、客观的，答案唯一或存在课堂明确规定的固定答案。
3. 老师之后明确回答、解释或验证了答案，或者答案能够由题面和课堂内容直接验证。
4. 问题具有实际作答机会，表现为明确互动指令、有效停顿，或问题后存在明显的回答气口。
5. 答案可以写成以下形式之一：
   数字；
   算式；
   一个字；
   一个词；
   简短固定短语；
   明确选项；
   “能/不能”“是/否”等判断答案；
   固定匹配关系；
   固定圈选结果。

以下内容不得收录：

1. 新知识导入或本节课即将讲解的核心问题。
2. 教学过渡语、起承转合或吸引注意力的反问。
3. 老师提出后立即自己回答，中间没有作答机会的问题。
4. 老师没有回答、没有解释、也无法验证答案的问题。
5. 开放性问题、多种答案均合理的问题。
6. 让学生自由表达方法、感受、想法或生活经验的问题。
7. 老师只是朗读大题题干，随后还要继续分析和拆解的问题。
8. “我们怎么办”“它们有什么区别”“可以怎么安排”等宽泛问题。
9. 只截取“用什么单位”“是不是”“对不对”等局部词语，脱离前后文形成的伪问题。
10. 为达到题量而收录的重复题、过渡语或低质量问题。
11. 只因存在静音就判断为互动题。剪辑静音本身不能证明老师在等待学生作答。

判断老师是在“读题”还是在“正式提问”时，重点查看后续行为：

- 如果老师接下来继续梳理题意、提取条件、拆解步骤，该位置通常只是读题或发起解决问题，不收录。
- 如果老师在问题或指令后停顿，随后直接公布、解释或验证答案，该位置通常是正式互动，可以收录。

第四步：处理同题的多种问法

同一道题附近可能出现题干、改问、列式提示、计算提示和互动指令。必须先归为同一个互动事件，再决定保留哪一个版本。

选择顺序如下：

1. 同一问题在短时间内连续多次提问时，一般优先选择最后一次完整提问。
2. 如果最后一句只是“选一选”“算一算”等指令，应把它与紧邻的完整问题原话组合，不得只输出孤立指令。
3. 优先选择后面有明确互动指令和真实作答停顿的版本。
4. 优先选择老师明确交给学生计算、选择、填空或判断的版本。
5. 同一问题既有宽泛题干，又有明确计算提问时，优先选择明确计算提问。
6. 优先选择单步问题，不选择随后还会拆成多个步骤的大问题。
7. 多个问法均合格时，优先选择有效等待时间更长的版本。
8. 如果同一知识点在课程后面形成了新的、独立的作答机会，可以作为另一道题；只有连续表达同一个作答机会时才去重。

示例：

老师先问“40个人大约重多少千克”，随后又说“来列一个算式”，最后明确问“25乘40等于多少，请你计算一下”。

这几句话属于同一道题。应优先选择最后的计算型提问，并把时间放在最后一句问题或指令说完之后。不要把前面的宽泛问题和后面的计算问题重复收录。

第五步：确定问题文字

“问题”列必须尽量保留老师真实说过的语言。

允许：

1. 删除“那么、来、好、我们看一下”等不影响含义的口头填充词。
2. 修正能够通过音频确认的明显ASR错字。
3. 将连续出现的“完整问题＋互动指令”按原顺序合并。
4. 为了语句完整，向前扩展并使用老师在相邻语句中真实说出的必要信息。

禁止：

1. 把老师的多句话总结成一句老师从未说过的话。
2. 自行补充老师没有说过的数字、条件、对象或术语。
3. 把课程内容概括成一道看似完整的问题。
4. 为了让问题更通顺而改写题意。
5. 根据答案反向编造问题。

如果输出问题无法在对应音频片段中找到相同或高度一致的原话，必须重新核对或排除。

第六步：确定问题时间点

问题时间点不是老师开始提问的时间。

问题时间点表示：
老师已经说完问题及其互动指令，学生应当开始作答的时刻。

具体规则：

1. 如果问题后有“请你选一选、算一算、填一填、想一想”等指令，并且该指令后存在真实作答停顿，时间点记录在该指令最后一个字说完之后。
2. 如果问题说完后存在明显停顿，但后面的“想一想、我们来算一算”等话语与继续讲解几乎连在一起，没有形成新的作答停顿，应优先把时间点放在前一个完整问题说完后的真实停顿处，不能机械地放在后续指令结束处。
3. 如果没有明确指令，但老师说完问题后留出作答停顿，时间点记录在问题最后一个字说完、停顿开始的位置。
4. 如果老师连续重复或改问同一道题，时间点记录在最终选中问法或最终有效互动指令结束后。
5. 指令本身不能自动证明存在作答机会。指令后立即进入解答或讲解、没有有效停顿时，一般不得把该位置作为互动时间点；应重新判断前面是否已有真实作答停顿，否则排除该题。
6. 不得使用问题开始时间、整段ASR开始时间、答案开始时间或旧表时间代替。
7. 必须结合单词级时间戳、静音检测结果和原音频复核。
8. 时间格式统一为HH:MM:SS.mmm，例如00:04:08.320。
9. 毫秒字段必须保留三位，但不得为了看起来精确而随意补写时间。
10. 每个时间点必须位于音频真实时长范围内，并按音频时间顺序排列。

示例一：

音频内容：
“几袋大米是一吨呢？A还是B？你来选择一下。”
“选择一下”说完后出现作答停顿。

正确时间点：
“选择一下”的“下”字说完之后。

错误时间点：
“几袋大米”开始说出的时间。

示例二：

音频内容：
“一只牙膏重50什么？”
停顿。
“想一想，你每天刷牙的时候拿起的牙膏是比较轻的……”

如果“50什么”之后有明显停顿，而“想一想”与后面的讲解几乎连续：

正确时间点：
“50什么”的“么”字说完、真实停顿开始的位置。

错误时间点：
“想一想”结束的位置。

第七步：确定答案

答案必须优先保留老师实际公布给学生的作答形式，而不是由AI自行转换成另一种等价表达。

答案来源优先级如下：

老师明确说出的选项字母
＞
老师明确说出的选项序号
＞
老师明确公布的具体答案内容
＞
能够由题面和后续讲解直接验证的答案。

具体规则：

1. 优先使用老师在作答停顿后公布、解释或验证的答案。
2. 答案必须能够从后续语音或明确题面中验证。
3. 答案只保留学生实际需要提交的最小充分内容，不要写成长篇解释。
4. 如果老师明确说出选项字母，例如“选A”“答案是B”“正确答案是C选项”，答案字段必须只记录“A”“B”“C”或相应字母。
5. 老师说“C选项”时，正式答案统一规范为“C”，不保留“选项”二字。
6. 即使老师随后解释了该选项对应的具体内容，也必须优先记录老师明确说出的选项字母，不得用选项内容替换字母。
7. 不得同时输出字母和选项内容。禁止写成“C选项”“C（1000）”“C，1000”“C选项（吨）”等形式。
8. 多选题中，如果老师明确说出多个选项字母，答案写成“A和C”或老师实际使用的最简等价形式。
9. 如果老师没有明确说出选项字母，但明确说出“第2个”“第三项”“最后一个”等选项序号，答案应保留老师实际说出的序号表达。
10. 不得仅根据选项顺序自行把“第3个”换算成“C”；只有音频明确说出字母C时，答案才能写“C”。
11. 如果老师没有明确说出选项字母或选项序号，才记录老师公布的具体内容答案，例如“千克”“1000”“大象”等。
12. 不得根据画面中的选项位置、选项内容或AI对题目的理解，覆盖老师明确说出的选项字母。
13. 计算题写最终数字或必要算式。
14. 填空题只写应填的字、词、数字或单位。
15. 判断题写“是/否”“能/不能”“对/错”等。
16. 连线题写成“A—②；B—①”这样的固定对应关系。
17. 圈选题写出应圈出的固定对象。
18. 如果老师没有给出答案、答案无法确定、存在多个合理答案或答案与题面冲突，必须排除或标记待人工复核，禁止猜测。

选择题示例一：

老师说：
“相邻的质量单位之间，它们的进率是多少呢？你来选一选吧。”
停顿后老师说：
“正确答案是C选项，相邻的两个质量单位之间，它们的进率是1000。”

正确答案：
C

错误答案：
1000
C选项
C（1000）

选择题示例二：

老师说：
“一卡车货物重3什么？请你选择一下。”
停顿后老师说：
“正确答案是C选项，卡车属于较重的大宗物品，常用吨作单位。”

正确答案：
C

错误答案：
吨
3吨
C选项
C选项（吨）

选择题示例三：

老师没有说出选项字母，只说：
“这里应该填千克。”

正确答案：
千克

不得仅根据“千克”在画面中位于C选项，就自行输出“C”。

第八步：题量与质量控制

1. 每个音频的目标题量为：音频总秒数÷60后向上取整，即平均每分钟约1道题。
2. 这里的“平均”是整段音频平均，不要求每一分钟都有一道题。
3. 如果初次结果没有达到目标，必须重新执行完整漏题回扫。
4. 重点寻找被关键词规则漏掉的计算题、填空题、判断题、选择题、圈画题和连线题。
5. 不得为了达到题量收录过渡语、重复题、开放题或没有作答机会的问题。
6. 完整复核后仍不足目标时，如实输出合格问题，并在最终处理摘要中说明实际题数、平均密度和不足原因。
7. 质量优先于凑数，但不得未经完整回扫就声称没有更多合格问题。

第九步：逐题质量复核

保存文件前，对每一行执行以下检查：

1. 原话检查：问题中的关键词、数字和对象能否在原音频中找到？
2. 互动检查：老师是否真的要求学生作答？
3. 停顿检查：问题或指令后是否存在真实作答机会？不能只根据疑问句或指令词判断。
4. 答案检查：老师之后是否回答、解释或验证了答案？
5. 答案形式检查：
   - 如果老师明确说出选项字母，答案是否只保留该字母？
   - 是否错误地使用选项内容替换了老师明确说出的字母？
   - 是否错误输出了“C选项”“C（答案内容）”等冗余形式？
   - 如果老师没有说出字母，是否避免了自行推断选项字母？
6. 客观性检查：答案是否唯一、固定且符合允许类型？
7. 去重检查：是否与相邻问题属于同一个作答机会？
8. 版本检查：是否已经选择连续多次提问中的最后一个或互动性更强的版本？
9. 单步检查：是否错误收录了随后还要拆解的大问题？
10. 时间检查：时间点是否在问题或有效指令结束之后，而不是开始位置？
11. 停顿位置检查：如果问题后和指令后存在多个停顿，是否选择了真正留给学生作答的停顿，而不是机械选择最后一句话结束的位置？
12. 粒度检查：是否严格做到一个问题、一行、一个时间点？
13. 原创内容检查：是否出现老师没有说过、由AI总结或补充的内容？
14. 音频范围检查：时间是否小于音频总时长？

对任何未通过检查的行，必须重新听取对应片段并修改或删除。

最后再执行一次反向核验：

仅根据表格中的“问题”和“答案”，定位回原音频。如果无法找到能够直接支持该问题和答案的原始语音片段，说明该行可能是概括、编造、断章取义或答案形式错误，必须重新处理。

对于选择题，还必须执行一次专项反向核验：

1. 定位老师公布答案的原始语音。
2. 如果老师明确说出选项字母，检查表格答案是否为该字母。
3. 如果表格填写的是选项内容，但音频明确说出了选项字母，必须改为选项字母。
4. 如果音频没有说出选项字母，不得仅根据选项内容反推出字母。

第十步：生成并验证文件

1. 创建Excel文件，主工作表命名为“问题抽取”。
2. 主工作表只包含四列：
   音频名称、问题时间点、问题、答案。
3. 不要把候选编号、审核意见、多个候选问法、开始时间、结束时间或内部推理写入正式工作表。
4. 一道问题一行，不合并问题，不合并时间点。
5. 按音频名称和问题时间点排序。
